VISTARA - THEME WORLD 2.0.0

1. Extract the extension ZIP into a NEW folder.
2. Open chrome://extensions in Chrome and enable Developer mode.
3. Choose Load unpacked and select the extracted folder containing manifest.json.
4. Source ZIP users can select Vistara (project root) or Vistara/dist.
5. Allow the desired website under Site access, then reload website tabs.
6. Open Vistara > Open Theme Studio to choose scenes or upload a local image.

Alt + Shift + V toggles coding Focus mode (configurable in extension shortcuts).
Advanced settings/site rules/import/export are linked from Studio's sidebar.

For updates, reusing the same extension folder and pressing Reload retains storage.
Removing/reinstalling may delete preferences and locally stored wallpapers.

Nine coding adapters are implemented; included screenshots/tests use local
representative fixtures. Live-site/native Chrome compatibility is not certified.
GitHub delivery does not imply Chrome Web Store approval or publication.
