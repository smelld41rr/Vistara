# Privacy — Vistara Theme World 2.0.0

Vistara is a local appearance tool. No backend, accounts, analytics, trackers, remote fonts, remotely hosted code, remote wallpapers or product-initiated network requests are included. User-entered share cards are downloaded locally; nothing is posted automatically.

Content scripts use selectors, computed colors and URL eligibility to identify containers to style. They do not read code editor values, private messages, credentials, cookies, browsing history or account data for collection. They do not intercept requests, code execution or submissions. On dedicated coding adapters, limited public difficulty labels and result/verdict labels are inspected to select optional scenes and show opt-in Accepted moments. These labels are not logged, transmitted or saved as browsing data. Share-card details are manually entered in Studio and are not scraped from submissions or profiles.

Small global appearance/accessibility preferences may use Chrome Sync through the user's own browser account. Site rules, custom presets, Studio preferences, fallback preferences and migration backups use local extension storage. Wallpapers are user-selected files, optimized locally and stored in extension-origin IndexedDB; filenames and image metadata stay local. The packaged background worker delivers a selected local image only to content scripts belonging to this extension. At most 20 wallpapers are retained. Delete them in Studio. Settings JSON exports contain image IDs, not image bytes, and do not transfer images to another browser. Downloaded backup files and shared PNG cards remain under the user's control. Uninstall may remove extension-managed data according to Chrome's behavior.

Permissions: `storage` for preferences; `activeTab` for the user-invoked active host and temporary tab commands; `scripting` only for recovery of the packaged content script on that active tab. Static HTTP/HTTPS content-script matches provide styling access. The packaged service worker reads the local image store and handles the declared focus keyboard command. No cookies, history, tabs, clipboard, webRequest or remote service permissions are requested. No unlimitedStorage permission is requested; image operations report local storage failure.

Imported settings have size/type/range validation and do not accept executable code, raw CSS or remote image URLs. Image uploads accept raster PNG/JPEG/WebP only and are re-encoded to JPEG. Built-in scene artwork is generated locally from original SVG definitions, with no external resources or third-party characters. Sound is generated locally, off by default and subject to browser interaction rules.

Future account/cloud/premium features would need separate consent and disclosure. None is implemented here.
