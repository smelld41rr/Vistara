A little guidance.

Why does a website look different?

Vistara styles selected containers, not every pixel. Sites change markup, and adapters may need updates. Use Compatibility mode or turn off the website if something looks wrong.

How do I allow website access?

Open Chrome’s Extensions menu, select Vistara, then “This can read and change site data” and allow the desired sites. Reload already-open tabs after installing or changing access. Manage extensions at chrome://extensions.

What cannot be themed?

Chrome’s toolbar, tabs, internal pages, Web Store, PDF viewer, closed shadow roots, and inaccessible frames. Sensitive login, checkout, medical, identity and government pages are automatically paused where detected. This detection is conservative, not exhaustive.

How can I improve performance?

Choose Compatibility mode to remove blur and ambient backgrounds. Lower blur and use Balanced mode for busy pages. Styling is limited to 160 non-nested surfaces, and mutations are batched.

How do I reset just one website?

Open Website rules, find the hostname, and choose Remove. This restores global defaults. Reset all website rules is a separate action.

Where do settings live?

Small preferences use Chrome Sync when available. Larger rule and preset collections stay in local extension storage. Sync failures are reported, with a local fallback preserved.

Privacy, without the fine print.

Vistara is a local appearance tool. It does not collect, transmit, log, summarize, or sell page content, messages, credentials, history, or account data. No analytics, remote fonts, remote code, or backend. We inspect selectors to identify surfaces; we never read form values or message text.

Why the site-access warning?

Content scripts need access to eligible HTTP/HTTPS pages to style them. Storage saves your preferences. ActiveTab identifies the website you open the popup on and sends temporary before/after commands. The scripting permission attaches the bundled content script to the active tab when missing. No history, cookies, clipboard, network interception, or tabs permission is requested.

Made to be yours.

Artwork and icons are locally generated for Vistara. The supplied concepts inspired the glass composition. Live site compatibility is best effort; browser fixtures are not a substitute for real-site release QA.
