# Screenshot provenance

These PNG files are **actual Chromium browser captures of compiled Vistara bundles** with simulated Chrome APIs, not illustrations and not live website screenshots. The environment's Chromium policy blocks installation of unpacked extensions. The local YouTube/ChatGPT representative fixtures are clearly labeled in their headers and use original abstract artwork with no third-party logos or private content.

- `youtube-midnight.png`: representative video-feed fixture; Midnight / Balanced.
- `chatgpt-midnight.png`: representative chat/composer fixture; Midnight / Balanced.
- `chatgpt-arctic.png`: the same fixture; Arctic / Balanced.
- `popup.png`: built popup UI in the browser harness; Midnight / Balanced.
- `options.png`: built options UI, desktop.
- `options-narrow.png`: built options UI at 500px with reduced motion.

Differences from the supplied concepts: abstract local imagery rather than real thumbnails, conservative semantic surface coverage, no copying of site logos, and static CSS ambient gradients. Production host sites can render differently and need the manual QA checklist.
