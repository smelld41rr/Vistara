# Liquid Glass screenshot provenance

Actual Chromium captures of the compiled v2.1 theme and popup on a **local functional ChatGPT fixture**, not an authenticated/live ChatGPT page or installed native MV3 extension. The page footer labels its provenance. Chrome APIs are simulated; native fixture handlers implement the mock send/stream/menu/file/state flows. No private account or conversation data was captured.

The supplied reference informed the pastel palette, edge orbs, frosted sidebar and pill composer. Browser chrome is deliberately absent from the theme. `home-peach-1672.png` is the desktop design comparison; `conversation-peach.png` shows code/table/conversation behavior; the numbered home images cover responsive widths; `popup-controls.png` shows the real built preference controls.
